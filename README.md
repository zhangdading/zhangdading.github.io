# 张大鼎 · 个人学术主页

[访问主页](https://zhangdading.github.io/)

GitHub Pages 从 `main` 分支根目录发布。首页为 `index.html`，经历、论文、项目与报告分别位于 `cv/`、`publications/`、`projects/`、`talks/`。各栏目正文在对应目录的 `index.html`，共用 `styles.css`。

在仓库根目录运行 `python -m http.server 8000`，通过 `http://localhost:8000/` 预览。

英文版在 `en/`，与中文版共用样式和图片。各栏目互设语言切换链接，更新内容时同步维护对应的页面。

公开简历保存在 `assets/`，更新 [中文经历页](https://zhangdading.github.io/cv/) 和 [英文经历页](https://zhangdading.github.io/en/cv/) 时同步更新 PDF。站点头像采用[刘牛网站公开的课题组照片](https://liuniu.fun/#team)。
